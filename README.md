# Studentenverwaltungssystem - C++

Ein einfaches konsolenbasiertes Studentenverwaltungssystem, das mit C++ entwickelt wurde.

## Funktionen

- Neue Studenten hinzufügen
- Alle Studenten anzeigen
- Studenten anhand der ID suchen
- Studenten löschen
- Studenten-ID, Name und Note verwalten
- Studentendaten in einer Textdatei speichern
- Überprüfung von Benutzereingaben

## Verwendete Technologien

- C++
- Standard Template Library (STL)
- Dateioperationen
- Datenstrukturen
- Visual Studio Code
- GCC / MinGW-w64

## Kompilieren

```bash
g++ main.cpp -o student_manager.exe
```

## Ausführen

Unter Windows PowerShell:

```powershell
.\student_manager.exe
```
